# Sac de Bonbons : La Ruée Sucrée

**Un max de friandises avant l'aube**

Joue en ligne sur : [https://games.hylst.fr/sacdebonbons/](https://games.hylst.fr/sacdebonbons/)

## Description
Un vertical jumper nerveux en pixel art avec quatre costumes au choix, bonbons dorés et multiplicateurs pour vider le quartier avant les monstres.

## Controles
| Contrôle | Action |
|---|---|
| Flèches / A-D | Déplacement horizontal |
| Espace | Rebond / Boost |
| Tactile | Boutons tactiles et inclinaison |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
